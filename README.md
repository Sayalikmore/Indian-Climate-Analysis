 Climate and Air Quality Analysis Dashboard

An interactive data analytics project using Excel and Power BI to analyze climate conditions, AQI trends, rainfall, 
temperature, humidity, and wind speed across Indian cities. The project includes data cleaning, preprocessing, visualization,
KPI cards, trend analysis, and future forecasting insights for environmental monitoring and weather analysis.

Power BI
